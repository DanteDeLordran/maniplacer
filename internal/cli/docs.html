Build manifests from values, not repetition.

Maniplacer combines one config with Go templates and writes rendered Kubernetes YAML. Start with the generated files, then adapt them to your workload.

The canonical workflow

  1. Configure. Put environment-specific values in config.json, config.yaml, or config.yml.
  2. Template. Reference those values from Kubernetes YAML under templates/<namespace>/.
  3. Generate. Run maniplacer generate; validated output is written below manifests/<namespace>/.

Config to template to output

1. Config

name: my-app
namespace: default
configValue: development

2. Template

apiVersion: v1
kind: ConfigMap
metadata:
  name: {{ .name | Quote }}
  namespace: {{ .namespace | Quote }}
data:
  APP_ENV: {{ .configValue | Quote }}

3. Rendered output

apiVersion: v1
kind: ConfigMap
metadata:
  name: "my-app"
  namespace: "default"
data:
  APP_ENV: "development"

Template functions

Base64
Base64-encodes a string.
Quote
Produces a quoted string.
ToUpper
Converts text to uppercase.
ToLower
Converts text to lowercase.

Pipelines pass a value through functions from left to right: {{ .value | Base64 | Quote }}.

Handle secrets separately

Base64 is encoding, not encryption. Do not commit real credentials in a Maniplacer config or rendered Secret. Supply secret values from uncommitted input at render time, or use your platform's external secret manager.
